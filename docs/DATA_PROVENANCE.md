# Data provenance

## Primary dataset

- Name: JapanEEG
- OpenNeuro accession: `ds007808`
- Intended snapshot: `1.0.0`
- DOI: <https://doi.org/10.18112/openneuro.ds007808.v1.0.0>
- License: CC0-1.0
- Raw data location: local `data/raw/ds007808/` (never committed)

The exact download command, snapshot metadata, file manifest, checksums, and
download date must be recorded before analysis. Raw files are immutable.

## Derived data

Every derived artifact must record its source files, preprocessing configuration,
software version, and content checksum. Third-party preprocessed mirrors may be
used for development but cannot replace validation against the authoritative
OpenNeuro release.
